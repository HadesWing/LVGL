# 本地部署流程（Windows + MSYS2，本机已验证）

> 本机环境：Windows x64 + MSYS2（`C:\msys64`）+ gcc 16.2.0 + cmake 4.4.4 + ninja 1.13.2 + SDL2 2.32.10
> 下面的每一步都是本机实际执行过的命令。**懒人版：直接跑 `scripts/setup_windows_msys2.sh`，一键完成全部步骤。**

---

## 第 1 步：安装 MSYS2（只装一次）

winget 走 GitHub 源会卡死，**用清华镜像**（81MB，2 秒下完）：

```bash
curl -L -o "$TEMP/msys2-latest.exe" https://mirrors.tuna.tsinghua.edu.cn/msys2/distrib/msys2-x86_64-latest.exe
$TEMP/msys2-latest.exe install --root C:/msys64 --confirm-command --accept-messages
```

> 装完若 GUI 卡在收尾不退出，文件其实已全部解压，可直接结束进程。

## 第 2 步：配置 pacman 国内镜像

编辑 `C:\msys64\etc\pacman.d\mirrorlist.mingw`（注意 TUNA 路径多一层 `mingw`）：

```ini
Server = https://mirrors.tuna.tsinghua.edu.cn/msys2/mingw/$repo/
Server = https://mirrors.ustc.edu.cn/msys2/mingw/$repo/
```

编辑 `C:\msys64\etc\pacman.d\mirrorlist.msys`：

```ini
Server = https://mirrors.tuna.tsinghua.edu.cn/msys2/msys/$arch/
Server = https://mirrors.ustc.edu.cn/msys2/msys/$arch/
```

## 第 3 步：绕过 gpg 密钥环初始化（Windows 上会卡十几分钟）

编辑 `C:\msys64\etc\pacman.conf` 第 41 行：

```ini
SigLevel    = Never      # 原值 Required；想恢复校验改回来即可
```

## 第 4 步：安装工具链（约 1 分钟）

在 **MSYS2 MINGW64** 终端中（开始菜单里的 "MSYS2 MINGW64"，不是 "MSYS"）：

```bash
pacman -Sy --noconfirm
pacman -S --needed --noconfirm mingw-w64-x86_64-gcc \
                               mingw-w64-x86_64-cmake \
                               mingw-w64-x86_64-ninja \
                               mingw-w64-x86_64-SDL2
# 验证
gcc --version && cmake --version && ninja --version && pkg-config --modversion sdl2
```

## 第 5 步：编译并运行（一条命令）

```bash
cd <仓库根目录>                      # 本机：lvgl_ws/lv_port_pc_vscode
git submodule update --init --recursive lvgl   # 首次需要

make            # 编译 + 运行
```

首次会全量编译 LVGL（973 个目标文件，-O3，约 5-15 分钟），之后改代码只编改动部分（秒级）。

`make` 系列命令：

| 命令 | 作用 |
|---|---|
| `make` / `make build` / `make run` | 编译+运行 / 只编译 / 只运行 |
| `make stats` | 每 5 秒打印 FPS / 内存 / 主循环耗时，明细写 `bin/stats.csv` |
| `make stress` | 压测：每 200ms 建删 8 个控件，查泄漏与碎片 |
| `make mem64` / `make mem SIZE=32768` | 用指定大小的内存池重编再跑 |
| `make debug` | 打开 LVGL 断言 |
| `make longrun` | 30 分钟长稳，到点自动汇总退出 |
| `make clean` | 删所有构建目录 |

临时改行为不用改代码：

```bat
set LVGL_STATS=1
set LVGL_RUN_SEC=60
make run
```

（bash 里写 `LVGL_RUN_SEC=60 make run`）

> **`make` 背后做了什么**：Makefile 只是转发壳，真正执行的是 `scripts/dev.sh`，
> 它负责 ①进入 MSYS2 工具链环境 ②把工作目录切到 ASCII 路径 `C:\lvgl_dev`（中文目录会让链接失败）
> ③cmake + ninja（`-j6`，规避 MSYS2 高并发的 fork 死锁）。原因见"已知坑速查"。


## 第 6 步：打包运行库 DLL（双击运行不报错的关键，只需做一次）

把 5 个 DLL 拷到 exe 同目录，让程序自包含（否则系统 PATH 里其他软件的旧版运行库会被优先加载，报「无法定位程序输入点 clock_gettime64」）：

```bash
cd bin
cp /c/msys64/mingw64/bin/{SDL2.dll,libgcc_s_seh-1.dll,libstdc++-6.dll,libwinpthread-1.dll,zlib1.dll} .
```

## 第 7 步（本机已配置）：git 推送走 SSH

本机代理会拦截 HTTPS 推送（`CONNECT tunnel failed, 502`），已配置：

```bash
# 1. 全局把 github HTTPS 改写成 SSH（已设置）
git config --global url."git@github.com:".insteadOf "https://github.com/"
# 2. SSH 密钥已注册（~/.ssh/id_rsa → GitHub 账号 HadesWing）
ssh -T git@github.com    # 验证：Hi HadesWing!
```

## 日常开发循环（改代码后）

```bash
make                       # 编 + 跑，一步到位
make stress                # 动过界面/内存相关代码，顺手压一遍（30 秒看内存有没有涨）
git add -A && git commit -m "..." && git push   # 每次修改都落库
```

## 已知坑速查

| 现象 | 解法 |
|---|---|
| `pacman` 404 | 镜像路径少写了 `mingw` 那层目录 |
| gpg 卡死 | `SigLevel = Never`（第 3 步） |
| `LV_USE_VECTOR_GRAPHIC requires ...THORVG` | `lv_conf.h` 中 `LV_USE_THORVG` 改 `1` |
| 双击报 `clock_gettime64` 找不到 | 第 6 步的 DLL 没拷 |
| 链接报 `cannot open output file ... Permission denied` | 旧 main.exe 还在运行，`taskkill /F /IM main.exe` 后重编 |
| `make build` 报 `C compiler is not able to compile a simple test program`（无其它信息） | make 拉起的子进程 PATH 不全，gcc 找不到 cc1/as 会**静默失败**。必须走 `scripts/dev.sh`（已内置） |
| 链接报 `cannot open output file ...\????\...\main.exe: No such file or directory` | 工程在中文路径下，cmake 的链接命令过 `cmd.exe` 时中文被转成 `?`。`dev.sh` 已自动改用 ASCII 联接 `C:\lvgl_dev` |
| 编译中途 cc.exe 全家挂起（CPU 时间不涨） | MSYS2 高并发 fork 死锁；杀进程重跑 `make build`（增量续编），`dev.sh` 已降到 `-j6` |
| 控制台中文乱码 | 源码 UTF-8 vs 控制台 GBK；`main()` 里 `SetConsoleOutputCP(CP_UTF8)` |
